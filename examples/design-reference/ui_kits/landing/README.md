# helm — Landing page UI kit

The marketing site. Single self-contained `index.html` (token CSS only, no bundle dependency).

**Structure** (mirrors the Investi landing's skeleton): sticky nav (mono wordmark + Features/Pricing/Blog/Manifesto + Sign in + ink Get started), centered hero ("The first agent-operated trading studio") on a soft pastel wash, macOS window mock of the workbench built from divs, numbered capabilities (01 one workspace / 02 shows its work / 03 guard rails you commit), the "Operated by Hermes" loop band (observe → re-backtest → refine → draft a diff → you approve), a 4-item FAQ, final CTA, and footer with the not-a-broker disclaimer.

Links through to `../console/index.html`.
