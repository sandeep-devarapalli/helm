# Security policy

## Supported versions

Security fixes are applied to the latest revision of `main`. This project does not currently maintain supported release branches.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or exposed credential. Use GitHub's private vulnerability reporting for this repository from the **Security** tab.

Include:

- the affected file, component, or workflow;
- steps to reproduce;
- the expected impact;
- any safe proof of concept; and
- a suggested mitigation, if available.

Do not access data that is not yours, disrupt services, execute live trades, or test against real broker accounts. Use synthetic data and local test environments.

We will acknowledge a complete report when a maintainer reviews it and coordinate disclosure after a fix is available.
